# Gestão de CAD — HDC Works

Este repositório guarda:

- `index.html` e `imagens/`: a página de vendas do Gestão de CAD;
- `versao.json`: o número da versão mais recente, que o sistema consulta para avisar os clientes;
- `Gestao-de-CAD.bin`: a versão mais recente **cifrada**. Sozinho, este arquivo não serve para nada: a chave de abertura é entregue pelo servidor de licenças da HDC Works somente para licenças válidas.

Nenhum dado de cliente fica aqui.
